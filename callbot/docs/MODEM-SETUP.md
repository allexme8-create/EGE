# Настройка GSM-модема и SIM МегаФона

## 1. Какой модем подходит

Нужен модем с **открытым голосовым каналом** (voice-capable):

| Модем | Голос | Примечания |
|---|---|---|
| Huawei E1550 / E171 / E173 | да | классика; аудио идёт через USB-аудио интерфейс модема |
| Huawei E3372 (режим Stick/TTY) | да | в режиме HiLink (`E3372h`) голоса нет — нужна перепрошивка |
| SIMCom SIM800 / SIM7600 | да | UART/GPIO + аналоговый аудиоразъём |
| Quectel M26 / EC25 | да | голосовой канал, часто нужен USB-переходник с PCM/I2S |
| Telit / Sierra Wireless | да | корпоративные шлюзы |
| «Свистки» только для интернета | **нет** | голос не передаётся физически |

Проще всего — модем Huawei с USB-аудио: он появляется сразу как `ttyUSB*` (AT-порт) и
USB-звуковая карта (воспроизведение/запись).

## 2. SIM МегаФона

1. Голосовой тариф (звонки на мобильные/городские), проверьте баланс — `*100#`.
2. Отключите PIN-код SIM (или оставьте, но тогда модем должен уметь его вводить;
   проще отключить).
3. Проверьте, что SIM не заблокирована для исходящих звонков и включена переадресация
   не мешает (не обязательно).
4. Ставьте SIM в модем до включения питания.

## 3. Linux: подключение

```bash
dmesg | tail -20                 # после подключения модема
ls /dev/ttyUSB*                  # AT-порт модема, обычно /dev/ttyUSB0
arecord -l                       # звуковые устройства
aplay -l
```

Часто у Huawei первый интерфейс (`ttyUSB0`) — AT-команды, второй/третий — служебные.
Проверка AT-порта:

```bash
python - <<'PY'
from app.telephony.modem import AtModem
m = AtModem("/dev/ttyUSB0")
info = m.open()
print(info)
print("баланс:", m.balance())
m.close()
PY
```

Ошибки доступа к порту лечатся добавлением пользователя в группу `dialout`:

```bash
sudo usermod -aG dialout $USER   # перелогиниться
```

`ModemManager` может перехватывать AT-порт — либо исключите устройство в его правилах,
либо отключите службу:

```bash
sudo systemctl disable --now ModemManager
```

## 4. Звук

Варианты:

* **USB-аудио модема** (Huawei): модем сам появляется как звуковая карта. В настройках
  сервиса укажите `plughw:<card>,0` для записи и воспроизведения.
* **USB-гарнитура/звуковая карта**, подключённая к голосовому разъёму модема
  (SIM800/Quectel): микрофон — на вход, динамик — на выход модема.
  Уровни проверьте `alsamixer -c <card>`.

Проверка записи и воспроизведения:

```bash
arecord -D plughw:1,0 -f S16_LE -r 8000 -c 1 -d 5 /tmp/test.wav
aplay -D plughw:1,0 /tmp/test.wav
```

В сервисе: «Оборудование» → «Пробный звонок» с озвучкой «Проверка связи» на ваш номер.

## 5. Команды, которые использует сервис

| Команда | Назначение |
|---|---|
| `ATZ`, `ATE0`, `AT+CMEE=1` | инициализация, отключение эха, текстовые ошибки |
| `AT+CPIN?`, `AT+CNUM`, `AT+COPS?`, `AT+CSQ` | SIM, номер, оператор, сигнал |
| `ATD<номер>;` | голосовой набор (точка с запятой обязательна) |
| `CONNECT` / `VOICE CALL: BEGIN` | абонент ответил |
| `BUSY`, `NO CARRIER`, `NO ANSWER` | занято / сброс / не ответил |
| `ATH` | отбой |
| `AT+VTS=<цифра>` | отправка DTMF в линию |
| `AT+DDET=1` | приём DTMF (`+DTMF: 1`) |
| `AT+CUSD=1,"*100#",15` | USSD-запрос баланса |
| `AT^DDSETEX=2`, `AT+QPCMV=1,2` | включение USB-аудиоканала (Huawei/Quectel) |

Разные прошивки отвечают по-разному; драйвер (`app/telephony/modem.py`) отправляет
команды с `allow_error=True`, поэтому незнакомые команды не ломают звонок.

## 6. Windows

* Установите драйвер модема, узнайте номер COM-порта в «Диспетчере устройств».
* `pip install pyserial`, в настройках укажите `COM3`.
* Запись/воспроизведение через `arecord`/`aplay` недоступны. Варианты:
  запускать сервис в WSL/Linux-машине либо доработать `AudioIO` под Windows
  (например, `sounddevice`/`pyaudio`) — интерфейс класса это позволяет.

## 7. Типичные проблемы

| Симптом | Причина / решение |
|---|---|
| `Таймаут команды AT` | не тот порт, занят ModemManager, нет прав |
| `+CME ERROR: 10` при `ATD` | SIM не вставлена/не готова |
| `+CME ERROR: 30` | нет сети или SIM без голосового тарифа |
| Набор идёт, но абонент ничего не слышит | не включён голосовой аудиоканал (`AT^DDSETEX=2`), не то устройство воспроизведения |
| Запись — тишина | неверное устройство записи или уровень микрофона |
| ASR возвращает пусто | не настроена модель/движок (см. «Оборудование») |
| Все ответы «нет ответа» | модем не пропускает голос (HiLink) или блокируется оператором |

## 8. Правовые ограничения

* Обзвон допускается только по клиентам, давшим согласие на обработку персональных
  данных и получение рекламных/сервисных сообщений (152-ФЗ, ст. 18 ФЗ «О рекламе»).
* Соблюдайте время звонков (настройка `calling_hours`) и стоп-лист.
* Не используйте сервис для массового «холодного» обзвона без согласия абонентов.
