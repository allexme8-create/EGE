# Обзвон+ — сервис обзвона клиентов с распознаванием ответов

Веб-сервис, который **сам обзванивает клиентов через GSM-модем с SIM-картой МегаФона**,
задаёт им заранее составленные вопросы, **записывает и распознаёт речь** и складывает
ответы в **таблицу данных** (веб + экспорт в Excel/CSV/JSON).

```
┌─────────────┐   AT-команды    ┌──────────────┐   USB-аудио   ┌────────────────────┐
│  Веб-интерфейс │ ─────────────▶ │ GSM-модем    │ ◀───────────▶ │ USB-звуковая карта │
│  (браузер)    │                │ SIM МегаФон  │               │ / гарнитура        │
└──────┬──────┘                 └──────────────┘               └─────────┬──────────┘
       │ HTTP/JSON                                                     │ WAV
┌──────▼─────────────────────────────────────────────────────────────────▼────────┐
│  Сервер (FastAPI): очередь обзвона · диалог · запись · ASR · разбор ответов · БД  │
│  SQLite: кампании, вопросы, контакты, звонки, ответы, события, стоп-лист          │
└───────────────────────────────────────────────────────────────────────────────────┘
```

## Живая демонстрация

Сервис уже запущен с демо-данными: три кампании, 14 контактов, 59 ответов
(в том числе сгенерированные только что «в прямом эфире»). Откройте интерфейс:

* **Обзор** — сводка, ход кампаний, журнал событий.
* **Таблица ответов** — строка = клиент, колонки = вопросы; можно слушать запись,
  править распознанное и выгружать в Excel.
* **Оборудование** — состояние модема/ASR/TTS, пробный звонок, проверка распознавания на файле.

## Возможности

* **Кампании обзвона** — сценарий из вопросов, приветствие/завершение, число попыток,
  таймауты, ограничение времени звонков (например, 09:00–20:00).
* **5 типов вопросов**: да/нет, выбор варианта, оценка 1–5, число, свободный ответ.
* **Вопросы озвучиваются** синтезом речи (Piper/espeak-ng) или готовым WAV-файлом,
  прикреплённым к вопросу; ответ абонента записывается (VAD-остановка по тишине).
* **Распознавание речи** офлайн: Vosk или whisper.cpp (или внешний HTTP-ASR).
* **Разбор ответа** из свободной фразы в значение для таблицы:
  «да, конечно» → `да`, «вариант два» → `Связь`, «на пятёрку» → `5`, «сорок два» → `42`.
  Поддержка ответа **нажатием клавиши** (DTMF).
* **Таблица ответов** прямо в браузере: строка = клиент, колонки = вопросы,
  подсветка ответов с низкой уверенностью, прослушивание записи, ручная правка,
  фильтры и поиск.
* **Экспорт**: XLSX (с «замороженной» шапкой), CSV для Excel (UTF-8 BOM, `;`), JSON,
  отдельная выгрузка расшифровок звонков.
* **Стоп-лист «Не звонить»**: абонент говорит «не звоните мне» — номер автоматически
  попадает в стоп-лист и больше не набирается.
* **Импорт контактов** CSV/TXT (CP1251/UTF-8, `;` `,` таб), нормализация номеров
  `8 999…`, `+7 (999)…`, `9991234567` → `+79991234567`.
* **Проверка оборудования**: порты модема, SIM/сеть/сигнал, баланс по USSD `*100#`,
  пробный звонок, ALSA-устройства, статус ASR/TTS.
* **Демо-режим** — работает без модема: эмулирует звонки и ответы, чтобы проверить
  сценарий и увидеть заполненную таблицу. Включён по умолчанию.
* Журнал событий по каждому звонку (набор, ответ, распознанный текст, ошибки).

## Быстрый старт

```bash
cd callbot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run.py --port 8000          # http://localhost:8000
```

По умолчанию сервис стартует в **демо-режиме**. Чтобы посмотреть, как всё работает:

1. «Кампании» → «＋ Новая кампания» (режим «Демо-эмулятор»).
2. Добавьте 2–4 вопроса и загрузите контакты (кнопка «⤓ Шаблон» даёт пример CSV).
3. «▶ Запустить обзвон» — через несколько секунд откроется «Таблица ответов»
   с распознанными ответами, уверенностью и записью.
4. «⤓ Скачать Excel» — готовая таблица.

Готовый демо-набор (кампании, контакты, результаты) можно создать командой:

```bash
python scripts/seed_demo.py        # заполняет data/callbot.db демо-данными
```

## Подключение модема и SIM МегаФона

1. Вставьте голосовую SIM МегаФона в модем, проверьте, что PIN отключён
   (или вводится в модеме), и что тариф позволяет исходящие звонки.
2. Подключите модем к серверу по USB. Определите порт:

   ```bash
   ls /dev/ttyUSB* /dev/ttyACM*          # Linux
   python -c "from serial.tools import list_ports; print([p.device for p in list_ports.comports()])"
   ```

3. Для **голоса** модем должен открывать голосовой канал: Huawei E1550/E171/E173/E3372
   (в режиме модема, не HiLink), SIM800/SIM7600, Quectel M26/EC25, Telit.
   Свистки «только данные» (например, E3372h в режиме HiLink) голос не пропускают.
4. Звук: к модему подключается USB-звуковая карта или гарнитура (в модемах Huawei это
   штатный аудио-интерфейс). Проверьте устройства:

   ```bash
   arecord -l && aplay -l
   ```

   В «Настройках» укажите, например, `plughw:1,0` как устройство записи и воспроизведения,
   либо оставьте пустым, чтобы использовать устройство по умолчанию.
5. «Настройки» → режим по умолчанию `modem`, порт модема, USSD баланса `*100#`.
6. «Оборудование» → «↻ Опросить модем» (модель, SIM, сигнал), «Проверить баланс»,
   «Пробный звонок» на свой номер.

> Законодательство: массовые обзвоны в РФ регулируются 152-ФЗ и правилами операторов.
> Используйте сервис для обзвона клиентов, давших согласие, соблюдайте время звонков
> и стоп-лист. Для больших объёмов используйте несколько модемов/шлюзов.

## Распознавание речи

| Движок | Установка | Плюсы |
|---|---|---|
| **Vosk** (офлайн, по умолчанию при наличии) | `pip install vosk`, скачать модель `vosk-model-small-ru-0.22` и указать путь | быстро на CPU, не требует интернета |
| **whisper.cpp** (офлайн) | собрать `whisper-cli`, скачать `ggml-small.bin`, указать пути | точнее на свободной речи |
| **HTTP-ASR** | свой сервис `POST {url}/transcribe` с полем `file` | можно подключить облачный/GPU-ASR |

```bash
# пример: Vosk
pip install vosk
wget https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip && unzip -d data/models
# «Настройки» → asr_engine=vosk, vosk_model_path=data/models/vosk-model-small-ru-0.22
```

Проверка: «Оборудование» → «Проверить на файле» (загрузите WAV с ответом).
Порог уверенности (`min_confidence`, по умолчанию 0,45) задаёт, какие ответы
подсвечиваются в таблице как «проверить».

## Озвучивание

* **Piper** (рекомендуется, естественный голос): `pip install piper-tts`, модель
  `ru_RU-irina-medium.onnx` в `data/models`; настройки `piper_bin`, `piper_model`.
* **espeak-ng**: `sudo apt install espeak-ng` (роботизированный, но ставится за секунду).
* **Свой WAV**: к каждому вопросу можно прикрепить файл (WAV/MP3/OGG/AMR) — он
  конвертируется в 8 кГц mono (нужен `ffmpeg`). Это лучший вариант для боевого обзвона:
  запись голоса диктора один раз.

```
callbot/
├── run.py                  точка входа (FastAPI + uvicorn)
├── app/
│   ├── api.py              REST API (47 эндпоинтов, документация /api/docs)

│   ├── answers.py          разбор фраз → значения (да/нет, варианты, оценки, числа)
│   ├── asr/                распознавание речи: Vosk, whisper.cpp, HTTP, stub
│   ├── tts.py              синтез речи и конвертация WAV для телефонии
│   ├── telephony/modem.py  AT-команды, аудио, USSD, DTMF, поиск портов
│   ├── exporting.py        XLSX/CSV/JSON/расшифровки звонков
│   ├── phones.py           нормализация номеров, импорт CSV
│   ├── db.py, settings.py, config.py
│   └── static/             интерфейс (HTML/CSS/JS без зависимостей)
├── scripts/seed_demo.py    демо-данные
├── tests/                  pytest: разбор ответов, телефоны, API, экспорт
└── docs/                   ARCHITECTURE.md, DEPLOY.md, MODEM-SETUP.md
```

## Настройки

Часть — переменные окружения (см. `.env.example`), остальное — в интерфейсе
«Настройки» и хранится в БД:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `CALLBOT_DATA` | `callbot/data` | каталог данных (БД, записи, модель) |
| `CALLBOT_PORT` | `8000` | порт сервиса |
| `CALLBOT_MODE` | `demo` | режим по умолчанию: `demo`/`modem` |
| `CALLBOT_MODEM_PORT` | — | порт модема `/dev/ttyUSB0`, `COM3` |
| `CALLBOT_AUDIO_PLAY` / `CALLBOT_AUDIO_REC` | — | ALSA-устройства `plughw:1,0` |
| `CALLBOT_ASR` | `auto` | `vosk`/`whispercpp`/`http`/`stub` |
| `CALLBOT_VOSK_MODEL` | `data/models/vosk-ru` | путь к модели Vosk |
| `CALLBOT_TTS` | `auto` | `piper`/`espeak`/`none` |
| `CALLBOT_USER` / `CALLBOT_PASSWORD` | — | Basic-аутентификация (если задан пароль) |

## API

Интерактивная документация — `/api/docs`. Основное:

```
POST /api/campaigns                       создать кампанию
POST /api/campaigns/{id}/questions        добавить вопрос
POST /api/campaigns/{id}/contacts/import  импорт CSV
POST /api/campaigns/{id}/start?mode=modem запустить обзвон
GET  /api/campaigns/{id}/results          таблица ответов (JSON)
GET  /api/campaigns/{id}/export?fmt=xlsx  экспорт в Excel
GET  /api/calls/{id}                      звонок + расшифровка + ответы
POST /api/text/parse                      проверить разбор фразы
POST /api/asr/transcribe                  распознать загруженный WAV
GET  /api/equipment?probe=true            состояние модема/аудио/ASR
```


## Ограничения и что дальше

* Один модем = один одновременный звонок. Для параллельного обзвона запустите
  несколько экземпляров/модемов или добавьте пул портов (см. `docs/ARCHITECTURE.md`).
* Демо-режим не совершает реальных звонков.
* Для «перебивания» шума и точного определения конца фразы в реальной телефонии
  полезно добавить echo suppression и настройку VAD-порогов (см. `docs/MODEM-SETUP.md`).
